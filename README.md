# Release Ops Lab

This repository is a sandbox for release-automation experiments.

## What's inside

- `CONTRIBUTING.md` — how to make changes here.
- `.github/workflows/ci.yml` — a manually triggered (`workflow_dispatch`) workflow that produces a `build-report` artifact.

## Tracking

Setup and experiment results are recorded on the `Rollout checklist` tracking issue, which serves as the audit trail for this lab.
